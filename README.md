# 🪟 Glassmorphism Chrome New Tab Engine

A sleek, high-end custom "New Tab" page for Chrome featuring a full Glassmorphism UI, theme management, and dark/light mode toggles. Transform your browsing experience from a blank white screen into a digital sanctuary.

## ✨ Features

* **Glassmorphism UI:** Beautiful frosted-glass effects with real-time backdrop blurring.
* **Theme Manager:** Switch between 5 premium presets:
    * *Cyber-Productivity, Lo-Fi Study, Minimalist, Data Junkie, and Nature Retreat.*
* **Dual Mode:** Seamlessly toggle between **Light Mode** and **Dark Mode**.
* **Customization:** Upload your own personal wallpapers and save them.
* **State Persistence:** Your settings and custom themes stay saved even after you close Chrome.
* **One-Click Reset:** Messed up your settings? Hit the reset button to go back to clean defaults.

## 🛠 Technology Used

* **HTML5 & CSS3:** Advanced CSS variables for theme switching and backdrop-filter effects.
* **JavaScript (Vanilla):** Light-weight logic for theme engine and DOM manipulation.
* **Chrome Storage API:** Keeps your preferences synced and saved locally.

## 🚀 How to Install (Make it your Default Page)

Follow these steps to load the extension into Chrome:

1.  **Download/Clone** this repository to your local machine.
2.  Open Google Chrome and navigate to `chrome://extensions/`.
3.  In the top right corner, enable **Developer mode**.
4.  Click the **Load unpacked** button that appears.
5.  Select the folder containing this project's files.
6.  Open a **New Tab**, and when Chrome asks if you want to keep the change, click **"Keep it"**.

### 🧼 Pro Tip: For the Cleanest Look
If you see a default Google footer or "Customize Chrome" button at the bottom:
* **Right-click** on that footer area.
* Select **"Hide shortcuts"** or check for the option to **"Hide footer in new tab"**. 
* This ensures only Ibrahim Khan's Glassmorphism UI is visible!
